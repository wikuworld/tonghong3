Panduan Uji — Outstanding (Alur Marketing)

Halaman memantau baris order yang belum selesai (qty masih ada sisa / outstanding). Data diambil dari Order Penjualan (SO) + pengiriman — bukan input master baru. Label ← dari … = sumber data. Ringkasan master: 00-korelasi-master-data.html · SO: order-penjualan-so.html.

1. Apa fungsi halaman ini?

  • Melihat sisa order per baris material dari SO yang belum berstatus «Selesai».
  • Mengisi remark marketing per baris.
  • Mengunduh laporan (CSV / Excel / Excel RETUR / Excel manual). Dengan checklist → hanya baris tercentang; tanpa checklist → ikut filter.
  • Centang baris lalu: Buat PI (multi-SO, customer sama), Jadwal kirim (qty + tanggal per baris), Susun kirim dari packing MRP yang sudah finish (ERP done + QC OK). Beberapa SO pelanggan sama boleh satu SJ. Gudang FG tidak membuat SJ.

Tidak ada di halaman ini: lanjut/mundur tahap Alur MKT, dan simpan snapshot. Lanjut tahap → menu Alur & daftar PO. Snapshot → menu Master & perencanaan kirim.
Outstanding muncul setelah Confirm (RKPO / PPIC bukan gerbang). Surat jalan hanya dari halaman ini.

2. Tampilan & filter

2.1 Toolbar

  • Counter baris terpilih (atau hint unduh mengikuti filter jika belum centang)
  • Menu Unduh: CSV · Excel · Excel RETUR · Excel manual — scope = checklist bila ada, else filter
  • Tombol checklist: Buat PI · Jadwal kirim · Susun kirim (packing)

2.2 Filter

5. Langkah uji coba

Uji 1 — Buka halaman & muat default

Prasyarat: Ada SO belum «Selesai» dengan sisa qty (balance > 0).

Langkah: Login (Admin/Marketing/PPIC) → Alur Marketing → Outstanding.

Yang diharapkan: Tabel terisi; baris balance 0 default tidak tampil; SO completed tidak muncul; footer jumlah qty/balance masuk akal.

Berhasil / Gagal
Uji 2 — Filter lembar kategori

Langkah: Pilih PROD, lalu CLAIM / SAMPLE / SUBCONT / RETUR. Nyalakan kolom lengkap.

Yang diharapkan: Daftar sesuai kategori SO. Label NO PO vs PO customer bisa berubah. Status material hilang di non-PROD. Slot jadwal berubah jumlahnya.

Berhasil / Gagal
Uji 3 — Filter status material & balance

Langkah: Coba Belum kirim / Sudah kirim. Ganti filter balance: sembunyikan 0 · semua · hanya > 0. Coba filter Dibatalkan.

Yang diharapkan: Belum kirim ≈ balance > 0; Sudah kirim ≈ balance ≤ 0; Dibatalkan hanya SO cancel; tanpa filter cancel tidak ikut.

Berhasil / Gagal
Uji 4 — Remark marketing

Langkah: Isi remark pada satu baris → keluar dari kotak → Muat ulang. (Opsional: coba akun tanpa hak ubah SO — textarea seharusnya tidak bisa diedit.)

Yang diharapkan: Remark tetap tersimpan di baris yang sama.

Berhasil / Gagal
Uji 5 — Jadwal kirim (terpilih, qty + tanggal per baris)

Langkah: Centang 2+ baris (boleh lintas SO) → Jadwal kirim. Isi qty & tanggal per baris (opsional: terapkan tanggal ke semua). Mode Tambah slot atau Ganti semua → Simpan.

Yang diharapkan: Slot jadwal terisi di kolom Kirim ke-n; sisa «Belum dijadwal» berubah.

Berhasil / Gagal
Uji 6 — Unduh file (filter vs checklist)

Langkah A: Tanpa centang → unduh CSV/Excel (mengikuti filter). Unduh Excel RETUR & manual.

Langkah B: Centang beberapa baris → unduh lagi → file hanya berisi baris tercentang.

Yang diharapkan: Tanpa checklist = filter; dengan checklist = hanya baris terpilih.

Berhasil / Gagal
Uji 7 — Korelasi SO selesai & pengiriman

Langkah: Ambil SO uji dengan balance > 0 di Outstanding. Setelah (uji di modul lain) qty terkirim penuh / SO jadi Selesai → kembali ke Outstanding + Muat ulang.

Yang diharapkan: Baris hilang atau balance berubah sesuai pengiriman; SO completed tidak lagi di daftar.

Berhasil / Gagal
Uji 8 — Cari no. PO & kode pabrik

Langkah: Filter No. PO dan/atau kode pabrik dari SO yang diketahui → Reset filter.

Yang diharapkan: Hasil mengecil sesuai kata kunci; Reset mengembalikan tampilan default.

Berhasil / Gagal

6. Korelasi dengan modul & master

Modul / master Hubungan dengan Outstanding
Order Penjualan (SO) ← sumber utama semua baris, qty, material, jadwal, remark PO. Aksi checklist: jadwal multi-SO, PI multi-SO (hanya baris tercentang), packing kirim
Delivery ← dibuat dari Outstanding via Susun kirim (packing done + QC OK). Marketing insert di Outstanding; halaman Delivery untuk pantau / cetak / mark sent (warehouse boleh Susun Kirim manual). Qty default = min(sisa packing, balance SO); parsial boleh; qty > sisa packing ditolak.
Master Customer / Brand Nama customer & brand di tabel = snapshot dari saat SO dibuat
Master Item Material / spek biasanya dari master saat input SO
Delivery / Production ← qty terkirim → mempengaruhi Balance & Aktual vs jadwal
Alur & daftar PO Lanjut tahap MKT & follow-up material (tidak di halaman Outstanding)
Master & perencanaan kirim Snapshot outstanding & perencanaan delivery (rute terpisah)
Material Outstanding (menu lain) Modul berbeda (tracking material follow-up/fulfillment) — jangan disamakan

Urutan uji realistis: buat SO lengkap → pastikan muncul di Outstanding → isi remark → unduh → (opsional) buat delivery agar balance berubah.
